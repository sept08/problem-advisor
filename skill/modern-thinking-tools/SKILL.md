# 现代思维工具

## 启用条件

用户需要判断且有重要取舍，或有一个未知足以改变行动时，使用本技能。成本低、容易撤回且信息已足够的问题，可以直接回答。用户点名要用某个工具时，先检查该工具的适用条件。用户当下需要倾听时，先回应感受，等对方需要分析时再使用框架。

## 运行规则

1. **确定真正要判断的事。** 梳理目标、硬约束、时间尺度和最可能改变行动的未知。缺失信息足以翻转建议，且无法通过合理假设或条件式建议继续时，再追问。涉及当前事实或专业规则时先核验。区分事实、推断、假设和价值偏好。
2. **选 1 个主工具。** 先检查是否有能直接决定可行性的硬约束，再按下表定位相关条目。主工具应改变问题表述、选项排序、判断的置信度或适用范围，或者提供成本更低的验证办法。找不到能改善判断的工具时，直接回答。
3. **做反证检查，按需加工具。** 先检查最可能推翻判断的证据或替代解释。检查后，如果还有会改变判断或行动的缺口，才加入补充工具。补充工具共 0–3 个，每个只解决一个缺口，例如解释机制、检验边界或设计行动。条目中提到的搭配也按这条规则选择。若工具结论冲突，检查目标、尺度、系统状态和证据质量是否一致，以及是否触及硬约束。
4. **让证据强度匹配后果。** 做选择时把现状及其成本纳入比较。低成本可逆的决定可以先小试，高损失、难撤回或牵涉他人权利的决定需要更强的独立证据。做预测时，有可靠的参考类就用基准率约束个案判断。依据不足时，给出条件情景和待验证的分支。概率和范围都需要输入依据。医疗、法律、财务和安全等高风险问题应核验当前事实，按需寻求专业意见。尊重用户与他人的选择权，工具应用应服务于透明合作。

## 作答

先回答用户的问题。一般只给**判断、关键依据和下一步**，用用户要求的篇幅和形式。有意义时给出改变判断的可观察信号。复杂任务再展开目标与约束、主工具如何改变分析、证据和替代解释、行动及复盘条件。用户点名某个工具，或工具名有助于理解方法时，可以在回答里写出工具名。条目的步骤和输出按本页的证据要求与回答篇幅取舍。

- **预测或风险**给出事件定义、时间窗口、主要卡点和更新信号。有依据时再给概率范围。
- **个人职业选择**围绕用户关心的条件设计验证，例如收入底线、转换成本和低风险试行。**新业务验证**关注谁会买、为什么会买、怎样获得付费信号和何时退出。
- **学习**给出目标表现、可练习的薄弱环节和能检验迁移的任务。
- **组织或系统改进**给出最可信的机制、可撤回的验证动作和衡量真实结果的指标。证据不足时，把机制写成待验证的假说。
